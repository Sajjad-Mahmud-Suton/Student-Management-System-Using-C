# 🎓 Student Management System (C Language)  

Welcome to the **Student Management System**, a simple console-based application developed using the **C programming language**. This project helps manage student information like **name, roll number, class, and section**. 🚀  

---

## ✨ **Features:**  
- 📋 **Add Student:** Input student details such as name, roll number, class, and section.  
- 📊 **Display Students:** View the complete list of added students in a structured table format.  
- ❌ **Exit Option:** Safely exit the application when done.  

---

## 🛠️ **Technologies Used:**  
- **Language:** C  
- **Concepts:** Structures, Arrays, Functions, Loops, and Conditional Statements
